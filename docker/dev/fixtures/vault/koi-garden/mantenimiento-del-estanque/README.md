# mantenimiento-del-estanque — Mantenimiento

**Estado:** Histórico
**Proyecto:** koi-garden
**Ticket:** sin ticket

Bitácora catch-all de tareas puntuales de mantenimiento sobre koi-garden que
no ameritan su propia carpeta de tarea.

## Regla de graduación

Trabajo puntual entra aquí salvo que existan 3 o más piezas del mismo tema:
a partir de la tercera pieza relacionada, ese tema se gradúa a su propia
tarea con ticket o slug propio, y deja de sumarse a esta bitácora.

## Contenido

- `scripts/limpiar-cache.sh` — script puntual de limpieza de caché.
- `reports/bitacora.md` — bitácora de las intervenciones registradas aquí.
