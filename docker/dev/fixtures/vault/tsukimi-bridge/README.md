# tsukimi-bridge (ficticio)

Servicio inventado que conecta la galería de `koi-garden` con su
almacenamiento de miniaturas. Existe únicamente como segundo proyecto de las
fixtures de desarrollo, para probar que el vault soporta más de un proyecto a
la vez y que el importador no mezcla tareas entre proyectos.
